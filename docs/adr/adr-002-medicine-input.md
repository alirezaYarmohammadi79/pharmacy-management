# ADR-002 : تصمیم گیری درباره نحوه تعریف دارو

## تاریخ : 1405/02/10

## وضعیت : تایید شده

## موضوع :

به دلیل اینکه تمامی دارو ها دارای چند شناسه برای شناسایی آنها در سیستم دارویی کل یک کشور یا یک حوزه وجود دارد، گزینه قابل استنتاج :

- تمامی دارو های تعریف شده یکتا هستند

## تصمیمات

بدون در نظر گرفتن اینکه دارو نام مشابه دارد ولی از شرکت های مختلفی است، پس دارو ها به صورت مجزا تعریف میشوند.

## عواقب

**نقاط قوت**

- سادگی سیستم
- کم هزینه بودن

**نقاط ضعف**

- تعداد رکورد بالا
- عدم مدیریت هزینه ذخیره سازی
